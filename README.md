# python-127

Beginner Python course. Each workshop has a lesson doc, a slide deck, and a
separate homework repo submitted via Pull Request.

# Programming Concepts
1. Variables - Data types - operations - method
2. if / else / elif - control flow
3. Loops - repeated operations
4. Functions - accept input - completes some instructions - gives result
5. Data Structures - method - sort - find element
6. Class
