Workshop 7

Lists

1. Why lists

Thirty students would need thirty variables. A list keeps many values in one variable.

2. Indexing: getting one item

Indexes start at 0, just like range(3). A negative index counts from the end.

Out of range

A list of three items has indexes 0, 1 and 2. Ask for one that does not exist and Python stops with an error.

names = ["Nina", "Luka", "Ana"]
print(names[3])
# IndexError: list index out of range

3. Changing an item

Unlike a string, a list can be changed after it is created. Assign to an index to replace that item.

4. Adding and removing items

List methods are called with a dot, like .upper() — but they change the list itself.

List methods

Five ways to add and remove. Only pop gives you the item back.

MethodWhat it does
append(x)add x to the end
insert(i, x)add x at index i, pushing the rest right
remove(x)remove the first x (error if there is none)
pop()remove the last item and return it
pop(i)remove the item at index i and return it

Try it — predict the output

Work out what prints before you reveal it.

letters = ["a", "b", "c", "d"]
letters.append("e")
print(letters[1], letters[-2], len(letters))
→ b d 5

Index 1 is the second item. After append the list is a b c d e, so -2 is d and there are 5 items.

5. Looping over a list

for walks through a list item by item, exactly like the letters of a string.

Looping with the position

Need the index too? Loop over range(len(...)) and index into the list.

6. Building a list in a loop

Start empty, append inside the loop, use it after: the accumulator, but for values.

7. Finding an element

in asks “is it there?”, .index() says where, .count() says how many.

Ask with in first

.index() stops with an error when the item is missing.

if "kiwi" in fruits:
    print(fruits.index("kiwi"))
else:
    print("No kiwi.")
# No kiwi.

Searching yourself

When the question is more than “is it equal?”, loop and return early the moment you find it.

8. Sorting

sorted() gives you a new list. .sort() sorts the list itself.

Never write x = x.sort()

.sort() returns None, so this replaces your list with None.

scores = scores.sort()
print(scores)
# None

Try it — predict the output

Work out what prints before you reveal it.

nums = [3, 1, 2]
result = nums.sort()
print(result, nums)
→ None [1, 2, 3]

.sort() changed nums itself and returned None. For a new sorted list, use sorted(nums).

9. min, max, sum

Three built-in functions answer the most common questions about a list of numbers.

scores = [82, 95, 67, 90]
print(min(scores), max(scores), sum(scores))
print(sum(scores) / len(scores))
# 67 95 334
# 83.5
