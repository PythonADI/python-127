break — leave the loop immediately

The remaining values of the range are never used.

continue — skip the rest of this pass

Jump straight back to the top and carry on with the next value.

Nested loops

The inner loop runs fully for every single pass of the outer one.

while vs for

Use for when you know the number of repeats. Use while when you repeat until something becomes true.

password = ""

while password != "python":
    password = input("Password: ").strip()
