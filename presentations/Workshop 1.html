Why data types matter

Python won't silently guess what you meant when combining a str and an int.

age = 25
print("Age: " + age)
# TypeError: can only concatenate str
# (not "int") to str

Type casting

Convert between types explicitly, and Python stops guessing.

age = 25
print("Age: " + str(age))  # works

f-strings

Build a string from variables without casting and concatenating by hand.

name = "Ada"
age = 25
print(f"{name} is {age} years old")
# Ada is 25 years old
