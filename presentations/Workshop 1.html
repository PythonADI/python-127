How does a computer work?

A computer runs on hardware and software. The CPU repeats one cycle, millions of times a second: fetch, decode, execute.

What is programming?

A computer only understands very simple instructions. We write source code in a language people can read, and the computer translates it into instructions it can run.

What is Python?

A high-level, interpreted, general-purpose programming language. It hides hardware details, and your code runs directly through the interpreter — no separate compile step.

Type casting

Convert between types explicitly, and Python stops guessing.

age = 25
print("Age: " + str(age))  # works
