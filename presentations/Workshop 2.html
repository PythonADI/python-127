Workshop 2

Input, Strings,
and Booleans

Getting input

input(...) prints a prompt, waits for the user to press Enter, and returns what they typed.

name = input("What is your name?\n")
print(f"Hello, {name}!")

Input is always text

Even if the user types 42, you get back the string "42".

age = input("How old are you?\n")
print(type(age))  # <class 'str'>
print(age + 1)
# TypeError: can only concatenate str
# (not "int") to str

Casting input

Wrap input() in int(...) or float(...) to do math with it.

age = int(input("How old are you?\n"))
print(f"In 5 years: {age + 5}")

Escape sequences

A backslash inside a string starts a special character.

SequenceMeaning
\nnew line
\ttab
\"double quote
\backslash

String methods

Call them with a dot. They return a new string and leave the original alone.

text = "   hello World   "
text.upper()   # "   HELLO WORLD   "
text.lower()   # "   hello world   "
text.strip()   # "hello World"
len("Ada")     # 3

Booleans

Every comparison produces True or False. Add = in an f-string to see both sides.

age = 20
print(f"{age >= 18 = }")
# age >= 18 = True

Truthiness

Empty or zero is False. Everything else is True.

Valuebool(...)
0False
-5True
""False
" "True
"0"True

Floats aren't exact

Decimals are stored in binary, so tiny errors creep in. Use round().

0.1 + 0.2          # 0.30000000000000004
0.1 + 0.2 == 0.3   # False
round(0.1 + 0.2, 2)  # 0.3

Constants

ALL_CAPS names tell other programmers: set once, never reassign.

VAT_RATE = 0.18
price = 100
print(price * (1 + VAT_RATE))
