Making decisions

An if statement lets a program choose whether to run a block of code.

age = 20

if age >= 18:
    print("You may enter.")

Indentation is the block

The if line ends with a colon, and every line of the block is indented by 4 spaces.

if age >= 18:
    print("You may enter.")
    print("Welcome!")
print("Have a nice day.")
# the last line always runs

else

The other path. Exactly one of the two blocks runs — never both, never neither.

age = 15

if age >= 18:
    print("You may enter.")
else:
    print("You are too young.")

elif — first match wins

Python checks top to bottom and stops at the first True. So order your conditions carefully.

score = 75

if score >= 90:
    print("Grade: A")
elif score >= 80:
    print("Grade: B")
elif score >= 70:
    print("Grade: C")   # this one wins
else:
    print("Grade: F")

= is not ==

One = assigns, two == compare. Here Python protects you with an error.

age = 20          # assigns
print(age == 20)  # compares: True

if age = 20:
    print("hi")
# SyntaxError: invalid syntax.
# Maybe you meant '==' here?

The "sunday" trap

Each side of or needs a full condition. A non-empty string is truthy, so the first version is always True.

day = "monday"

# WRONG: always True
if day == "saturday" or "sunday":
    print("Weekend!")

# correct
if day == "saturday" or day == "sunday":
    print("Weekend!")

Inside a range

Python lets you chain comparisons the way mathematics writes them.

temperature = 22

if 18 <= temperature <= 25:
    print("Comfortable.")

# same as:
# 18 <= temperature
#   and temperature <= 25

Any value is a condition

if name: is the Python way to say "if this isn't empty".

name = input("Your name:\n").strip()

if name:
    print(f"Hello, {name}!")
else:
    print("You typed nothing.")

in and not in

For strings, in asks whether one piece of text sits inside another. It gives you a bool.

email = input("Email: ").strip()

if "@" in email:
    print("Looks like an email.")
else:
    print("That's missing an @.")

Choosing a value in one line

Use a conditional expression to pick a value — not to run several statements.

age = 20

status = "adult" if age >= 18 else "minor"
print(status)      # adult
