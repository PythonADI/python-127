Functions

Why functions

Name a block of code and run it by calling that name, instead of retyping it.

Parameters — feeding information in

name only exists inside greet, set to whatever the caller passes.

return — sending a value back

return hands a value to the caller and ends the function immediately.

Functions without return

No return statement means the function hands back None.

Default parameter values

A parameter with a default can be skipped by the caller.

Scope — variables inside a function stay inside

result is created fresh each call and gone once the function returns.

Try it — predict the output

Work out what prints before you reveal it.

def mystery(x):
    return x * 2 + 1

print(mystery(3))
→ 7

mystery(3) returns 3 * 2 + 1, which is 7.

Try it — predict the output

Two calls, one default parameter.

def shout(word="hi"):
    return word.upper() + "!"

print(shout())
print(shout("bye"))
→ HI!
→ BYE!

The first call omits word, so the default "hi" is used. The second supplies "bye", overriding it.
