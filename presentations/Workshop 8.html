Workshop 8

Dictionaries

1. Why dictionaries

A list finds things by position. To find Luka's phone you first have to find where Luka is.

names = ["Nina", "Luka"]
phones = ["555-1234", "555-9876"]
print(phones[names.index("Luka")])
# 555-9876

Find by key

A dictionary pairs each key with a value. Curly braces, key: value, commas between pairs.

2. Getting a value

Square brackets with the key. .get() is the safe version. in checks keys.

Missing key

Ask for a key that is not there and Python stops with an error. Use in or .get() first.

ages = {"Nina": 19, "Luka": 22}
print(ages["Ana"])
# KeyError: 'Ana'

3. Adding, changing and removing

Assign to a key: a new key is added, an existing key is replaced. A key appears only once.

Try it — predict the output

Work out what prints before you reveal it.

stock = {"apple": 5, "pear": 2}
stock["apple"] = 7
stock["plum"] = 1
print(len(stock), stock.get("kiwi", 0), "pear" in stock)
→ 3 0 True

"apple" already existed, so it was replaced, not added. Only "plum" is new: 3 keys. "kiwi" is missing, so .get gives the default 0.

4. Looping over a dictionary

A for loop over a dictionary gives you the keys.

Key and value together

.items() gives both — unpack them into two variables.

5. Counting with a dictionary

Seen it before? Add 1. First time? Start it at 1.

Counting in one line

.get(word, 0) gives 0 the first time, so the if disappears.

counts = {}
for word in words:
    counts[word] = counts.get(word, 0) + 1

Try it — predict the output

Work out what prints before you reveal it.

ages = {"Nina": 19, "Luka": 22}
for name in ages:
    print(name)
print(19 in ages)
→ Nina
→ Luka
→ False

Looping and in both work on the keys. 19 is a value, not a key.

6. Tuples

Like a list, but with round brackets — and it cannot be changed. return a, b and .items() already give you tuples.

point = (3, 5)
print(point[0])
x, y = point
print(x + y)
# 3
# 8

point[0] = 10
# TypeError: 'tuple' object does
# not support item assignment
