1. The problem: copy-paste HTML

Every page repeats <html>, <head> and the menu. Add one link → edit every file.

<html> <head><title>Portal</title></head> <body> <a href="/about/">About</a> [hl@1] <h1>My first web app</h1> ...
<html> <head><title>About us</title></head> <body> <a href="/">Home</a> [hl@1] <h1>About Us</h1>

One base, many pages

base.html has the skeleton and holes (blocks). Pages extend it and fill only the holes.

<html> <head> <title>{% block title %}Portal{% endblock %}</title> [hl@1] </head> <body> <nav> <a href="/">Home</a> | <a href="/about/">About</a> | <a href="/blog/">Blog</a> </nav> {% block content %}{% endblock %} [hl@2] </body> </html>
{% extends "base.html" %} {% block title %}About us{% endblock %} [hl@1] {% block content %} [hl@2] <h1>About Us</h1> {% endblock %}

What the browser actually gets

Django glues the two files together on the server. The browser receives one normal HTML page.

2. Named URLs

Give every path a name. Templates ask for the name, Django fills in the address.

urlpatterns = [ path('admin/', admin.site.urls), + path('', home_view, name="home"), + path('about/', about_view, name="about"), + path('blog/', blog_view, name="blog"), ... ]
<nav> + <a href="{% url 'home' %}">Home</a> + <a href="{% url 'about' %}">About</a> + <a href="{% url 'blog' %}">Blog</a> </nav>

✓ Change 'about/' to 'about-us/' — every link still works.

4. Search

A GET form puts the text into the URL: /?search=milk. The view reads it from request.GET.

<form method="get"> <input name="search" value="{{ search }}"> [hl@1] <button>Search</button> </form> {% for product in products %} ... {% empty %} [hl@3] <li>No products found.</li> {% endfor %}
def home_view(request): search = request.GET.get("search", "") [hl@1] products = Product.objects.all() if search: products = products.filter(name__icontains=search) [hl@2] return render(request, "index.html", {"products": products, "search": search})
